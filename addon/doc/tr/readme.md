# Metin Dolaşımı #

* Yazar: Tony Malykh
* [kararlı sürümü][1] indir

Metin Dolaşımı tek bir tuşla web sayfalarındaki metin içeren paragraflara
atlamanızı sağlar.

## Kısayol Tuşları: 
* Alt+Shift+Aşağı ok: Sonraki metin paragrafına gidin.
* Alt+Shift+Yukarı ok: Önceki metin paragrafına gidin.

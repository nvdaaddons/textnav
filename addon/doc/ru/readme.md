# Уведомление

Дополнение TextNav больше не поддерживается. Начиная с версии 2024.2
функциональность TextNav включена в ядро NVDA. Оно реализовано в виде
быстрого навигационного жеста и по умолчанию назначено на `p` и `shift+p`.

# nvda-text-nav

TextNav - это новый, более совершенный способ навигации в Интернете для
незрячих. Он позволяет быстро находить читаемое содержимое практически на
любой веб-странице в Интернете всего одним нажатием клавиши. Ознакомьтесь с
короткой аудио-демонстрацией (7-минутный аудиофайл):

https://soundcloud.com/user-977282820/textnav-promo

Точнее, TextNav добавляет нажатие клавиши для перехода к следующему или
предыдущему абзацу текста - это абзац, содержащий одно или несколько
предложений, разделенных точками.  Эта функция может быть полезна для
быстрого поиска текстовой части веб-страницы или для перехода по меню,
рекламным объявлениям и другим не важным элементам страницы.

TextNav ранее был частью дополнения
[SentenceNav](https://github.com/mltony/nvda-sentence-nav/).
## Комбинации клавиш
* Alt+Shift+Стрелка вниз: Перейти к следующему текстовому абзацу.
* Alt+Shift+Стрелка вверх: Перейти к предыдущему текстовому абзацу.

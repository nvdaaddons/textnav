# Aviso

El complemento TextNav se ha descontinuado. La funcionalidad de TextNav se
ha integrado en el núcleo de NVDA a partir de la versión 2024.2. Se ha
implementado como un gesto de navegación rápida y se ha asignado por defecto
a `p` y `shift+p`.

# nvda-text-nav

TextNav es una nueva forma mejorada de navegar por Internet a
ciegas. Permite localizar rápidamente contenido legible en casi cualquier
página web de Internet con un único atajo de teclado. Echa un vistazo a una
breve demostración en audio (archivo de audio de 7 minutos):

https://soundcloud.com/user-977282820/textnav-promo

Más concretamente, TextNav añade una orden para saltar al siguiente o
anterior párrafo de texto - que es un párrafo que contiene una o más
oraciones separadas por puntos.  Esta característica podría ser útil para
encontrar rápidamente la parte textual de una página web o para saltarse
menús, anuncios y otros elementos de la página sin importancia.

TextNav comenzó siendo parte del complemento
[SentenceNav](https://github.com/mltony/nvda-sentence-nav/).
## Atajos de teclado
* Alt+Shift+Flecha abajo: Ir a siguiente párrafo de texto.
* Alt+Shift+Flecha arriba: Ir al párrafo de texto anterior.

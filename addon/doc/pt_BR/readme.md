# Navegação em texto #

# Aviso

O complemento TextNav foi descontinuado. A funcionalidade TextNav foi
incorporada ao núcleo do NVDA a partir da versão 2024.2. Ela é implementada
como um gesto de navegação rápida e é atribuída por padrão a `p` e
`shift+p`.

# nvda-text-nav

O TextNav é uma nova e melhor maneira de navegar na Internet para cegos. Ele
permite que você encontre rapidamente conteúdo legível em praticamente
qualquer página da Web na Internet com apenas um toque de tecla. Confira uma
breve demonstração em áudio (arquivo de áudio de 7 minutos):

https://soundcloud.com/user-977282820/textnav-promo

Mais precisamente, o TextNav adiciona um pressionamento de tecla para saltar
para os parágrafos de texto seguintes ou anteriores, ou seja, um parágrafo
que contém uma ou mais frases, separadas por pontos.  Esse recurso pode ser
útil para localizar rapidamente a parte textual de uma página da Web ou para
ignorar menus, anúncios e outros elementos não importantes da página.

O TextNav era anteriormente parte do complemento [SentenceNav]
(https://github.com/mltony/nvda-sentence-nav/).
## Teclas de atalho
* Alt+Shift+Seta abaixo: Vai ao próximo parágrafo de texto.
* Alt+Shift+Seta acima: Vai ao próximo parágrafo de texto.

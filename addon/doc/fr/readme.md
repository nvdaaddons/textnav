# Avis

L'extension TextNav a été abandonnée. La fonctionnalité TextNav a été
fusionnée dans le noyau NVDA à partir de la version 2024.2. Il est
implémenté comme un geste de navigation rapide et est attribué par défaut à
`p` et `maj+p`.

# nvda-text-nav

TextNav est une nouvelle meilleure façon de naviguer sur Internet pour les
aveugles. Il vous permet de trouver rapidement du contenu lisible sur
presque toutes les pages Web d'Internet par la frappe d'une seule
touche. Découvrez une courte démo audio (fichier audio de 7 minutes) :

https://soundcloud.com/user-977282820/textnav-promo

Plus précisément, il ajoute un raccourci à frapper pour passer aux
paragraphes de texte précédents ou suivants, c’est-à-dire un paragraphe
contenant une ou plusieurs phrases séparées par des points.  Cette
fonctionnalité peut être utile pour trouver rapidement la partie textuelle
d’une page Web ou pour ignorer les menus, les publicités et d'autres
éléments de page non importants.

TextNav faisait auparavant partie de l'extension
[SentenceNav](https://github.com/mltony/nvda-sentence-nav/).
## Touches de commandes
* Alt+Maj+Flèche Bas : Aller au paragraphe de texte suivant.
* Alt+Maj+Flèche Haut : Aller au paragraphe de texte précédent.
